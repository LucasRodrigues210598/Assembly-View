## 🎯 Visão Geral

O Painel do Montador foi projetado especificamente para uso em obras, com foco em:
- **Visualização 3D** completa do móvel
- **Checklist interativo** de conferência de peças
- **Guia passo a passo** claro e objetivo
- **Uso offline** (quando disponível conexão)

---

## 📱 Funcionalidades

### 🎨 Visualização em 3D

No módulo "Visualizar 3D", você pode:

#### Controles Disponíveis
- **Rotação**: Use os botões de seta para girar o móvel
  - ↺ Gira horizontalmente (vista frontal/lateral)
  - ⬆️⬇️ Gira verticalmente (sobre o eixo Y)
  
- **Zoom**: Aumente ou diminua a visualização
  - 🔍 Zoom in: Clique no ícone de lupa para aproximar
  - 🔙 Zoom out: Afastar para ver todo o móvel
  
- **Modo Explosão**: 
  - Botão "Explodir" separa todas as peças
  - Ideal para entender a estrutura interna
  - Clique novamente para voltar ao modo normal

#### Especificações do Módulo
A barra lateral exibe:
- Medidas: largura, altura, profundidade
- Material: tipo e acabamento (ex: MDP 15mm Branco/Carvalho)
- Ferragens incluídas (dobradiças, puxadores, etc.)

---

### ✅ Conferir Peças

No módulo "Conferir peças", você pode:

#### Checklist Interativo
Clique no checkbox de cada peça para marcar como conferida.

**Barra de Progresso**: Mostra quantas peças foram conferidas (ex: "7 de 15 = 47%")

#### Exemplo de Lista de Peças
- **Lateral esquerda** - 600 x 300 x 15 mm - MDP ✓
- **Lateral direita** - 600 x 300 x 15 mm - MDP ✓
- **Tampe superior** - 800 x 300 x 15 mm - MDP ✓
- **Prateleira** - 768 x 280 x 15 mm - MDP ✓
- **Puxador** - 160 mm - Metal ⬜

Lembre-se: Marque todas as peças antes de iniciar a montagem!

---

### 📋 Seguir Montagem

No módulo "Seguir montagem", siga o passo a passo na ordem correta.

#### Cada Etapa Inclui
1. **Número da etapa**: Ex: "Passo 3 de 12"
2. **Título**: Ação principal (ex: "Fixar a prateleira")
3. **Descrição**: Instruções detalhadas
4. **Imagens ilustrativas**: Fotos ou desenhos de referência
5. **Dicas**: Observações importantes para evitar erros
6. **Ferramentas necessárias**: Lista do que você precisa

#### Dicas Importantes
- **"Verifique se a prateleira está no nível correto"**
  - Use um nível de obra para garantir alinhamento
  
- **"Use um martelo de borracha para facilitar o encaixe"**
  - Evita danificar as peças de madeira
  
- **"Confira se os suportes estão bem fixos"**
  - Aperte todos os parafusos antes de prosseguir

#### Ferramentas Comuns por Etapa
- **Chave Philips**: Parafusadeiras, fixação geral
- **Martelo de borracha**: Ajustes finos, alinhamento
- **Talharia**: Cortes precisos (quando necessário)
- **Fresa**: Cantoneiras e proteção

#### Navegação entre Etapas
- Botão "Passo anterior": Voltar para revisar instruções
- Botão "Marcar como concluído": Avançar para próxima etapa
- Texto "Pular para o próximo passo →": Atalho rápido

## 💡 Melhores Práticas

### ✅ Antes de Começar
1. Confira todas as peças na lista (marque tudo no checklist)
2. Verifique se tem todas as ferramentas necessárias
3. Leia todas as observações do projetista
4. Tire fotos das peças antes de começar (para referência futura)

### 🛠️ Durante a Montagem
- **Siga a ordem**: Cada passo está na sequência correta
- **Não pule etapas**: Mesmo que pareça óbvio, siga o guia
- **Marque cada etapa como concluída**: Mantém você no caminho certo
- **Dúvidas?**: Volte ao passo anterior e releia as instruções

### ⚠️ Se Houver Erros
1. Pare imediatamente
2. Verifique se todas as peças anteriores estão marcadas como conferidas
3. Releia o passo anterior
4. Compare com as imagens ilustrativas
5. Registre a observação no campo "Notas" (se disponível)
